# 手動テスト手順書

このドキュメントでは、MVP リリース前に実施すべき手動テストの手順を記載します。  
すべての項目が ✅ になることを確認してください。

---

## テスト環境

- **実施環境**: ローカル開発環境（wp-env + Docker）
- **URL**: 
  - BrowserSync: http://localhost:3000
  - wp-env直接: http://localhost:8888
- **ブラウザ**: Chrome（最新版）、Safari（最新版）、モバイルブラウザ（実機またはデベロッパーツール）
- **WordPress バージョン**: 6.5.5-ja
- **テーマ**: sample-wordpress

---

## 1. 開発環境セットアップテスト

### 1.1 初回セットアップ
- [ ] Docker が起動している
- [ ] Node.js v18.20.8 が使用されている（`node -v` で確認）
- [ ] `npm install` が成功する
- [ ] `npm run start` でエラーなく起動する
- [ ] http://localhost:8888 にアクセスできる
- [ ] http://localhost:3000 にアクセスできる（BrowserSync）

### 1.2 テーマの有効化
- [ ] WordPress 管理画面（http://localhost:8888/wp-admin）にログインできる
  - ユーザー名: `admin`
  - パスワード: `password`
- [ ] 「外観 > テーマ」で `sample-wordpress` テーマが表示される
- [ ] テーマを有効化できる
- [ ] 有効化後、エラーが表示されない

## 2. テーマ基本機能テスト

### 2.1 トップページ表示
- [ ] http://localhost:3000 でトップページが表示される
- [ ] ヘッダーが表示される
- [ ] フッターが表示される
- [ ] レイアウトが崩れていない

### 2.2 記事ページ表示

- [ ] トップページから記事にアクセスできる
- [ ] 記事詳細ページが表示される（index.php がフォールバックとして機能）
- [ ] 記事タイトル・本文・投稿日が表示される

### 2.3 固定ページ表示

## 3. Sass + Gulp 機能テスト

### 3.1 Sass コンパイル
- [ ] `themes/sample-wordpress/sass/style.scss` を編集
- [ ] 保存時に自動で `style.css` が生成される
- [ ] Gulp のコンソールにエラーが表示されない

### 3.2 ホットリロード（BrowserSync）
- [ ] SCSS ファイルを編集・保存
- [ ] ブラウザが自動でリロードされる（またはCSSが差し替わる）
- [ ] スタイル変更が即座に反映される
- [ ] PHP ファイル（例：header.php）を編集・保存
- [ ] ブラウザが自動でリロードされる

---

## 4. Contact Form 7 テスト

### 4.1 プラグイン確認
- [ ] 管理画面「プラグイン」で Contact Form 7 が有効化されている
- [ ] 「お問い合わせ > コンタクトフォーム」が表示される

### 4.2 フォーム作成
- [ ] 管理画面でフォームを作成
- [ ] 以下の項目が含まれる：
  - 名前（必須）
  - メールアドレス（必須）
  - 本文（必須）
- [ ] ショートコードをコピー

### 4.3 フォーム埋め込み
- [ ] 固定ページ「お問い合わせ」を新規作成
- [ ] ショートコードを本文に貼り付け
- [ ] 公開する

### 4.4 フォーム送信テスト
- [ ] フロント側でお問い合わせページにアクセス
- [ ] フォームが表示される
- [ ] 必須項目を空欄で送信 → エラーメッセージが表示される
- [ ] すべての項目を入力して送信 → 送信完了メッセージが表示される
- [ ] （可能であれば）管理者メールアドレスに通知メールが届く

**注意**: wp-env のローカル環境ではメール送信が機能しない場合があります。  
その場合、MailHog などのメールテストツール導入を検討してください。

## 既知の問題・制限事項

### ローカル環境の制限
- メール送信機能は wp-env のデフォルト設定では動作しません
  - MailHog などのツールを使用して確認することを推奨
- SSL（HTTPS）は未設定です（本番環境では必須）

### MVP の制限事項
- テンプレートファイルは最小限（index.php がフォールバック）
- SEO 最適化は基本的な OGP のみ（構造化データ等は未実装）
- 多言語対応なし
- 自動テストなし（手動テストのみ）
